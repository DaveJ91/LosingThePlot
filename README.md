# losingThePlot

A graphing library for finance, tax and legal professionals, built as one self-contained HTML page.

**Live site:** https://davej91.github.io/LosingThePlot/

## What's in it

- 1,661 charts across ten chapters: How big, How it changes, What stands out, Does it add up, How it connects, Where it happens, What it is like, Telling the story, Getting the work done, and From elsewhere.
- A Vibes panel with 351 palettes in six families and eleven presets, plus optional background textures.
- Paste your own data or download a CSV on every chart, with sample rows and six professional data packs.
- A plain-sentence description alongside every chart, and reduced motion respected.
- Agent notes embedded in the page, so a coding agent can find and reuse components.

## Design rules

Swiss modern, white ground, square corners, rules rather than cards, Irish (en-IE) number formatting, and illustrative Acme figures rather than real client data.

## Running it

There's nothing to install. Open `index.html` in a browser, or visit the live site.
